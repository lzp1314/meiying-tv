# 魅影TV · 空壳 IPTV 播放器

一个用于管理并播放自有 IPTV 订阅的开源播放器骨架，手机与 Android TV 共用一个安装包。

**它不提供任何内容。** 安装包里没有内置频道、没有内置订阅地址、没有可播放的流。首次打开时源列表为空，用户需自行添加自己有权使用的 M3U 订阅。

## 能力

- **多源管理**：添加、切换、编辑、刷新、删除多个订阅源，本地持久化；可锁定某个源，锁定后每次启动固定使用它。
- **添加源**：设备显示二维码与配对码，用另一台手机扫码后在网页里填表推送；设置里同时提供手动填写表单（名称、订阅地址、节目单地址）。设备本身不调用摄像头、不需要相机权限。
- **启动即全屏**：打开直接进入全屏播放，不设首页；手机端自动横屏并隐藏系统栏。
- **侧栏入口**：手机点屏幕左半区出「频道」、右半区出「设置」；电视端按菜单键（三横线键同码）呼出，左侧浮出「频道 / 信号源 / 设置」三栏，右侧画面保持可见。呼出时光标定位到当前正在看的频道与信号源。
- **播放控制**：电视端 OK 键暂停/继续，手机端双击画面暂停/继续；侧栏内 OK 仍用于确认选项。暂停时画面停在当前帧，恢复不重新拉流。
- **遥控器**：上下键换台（方向可在设置里反转），CH+/CH- 固定为下一个/上一个；退到后台立即停播，避免声音残留。
- **频道侧栏**：按源分段列出全部已加载的源，非当前源读本地快照、不额外联网；点任意源的任意频道即切源起播。
- **手势（手机）**：左侧竖滑换台、中间竖滑调亮度、右侧竖滑调音量；亮度只作用于当前窗口。
- **离线缓存**：先按缓存秒开起播，缓存两小时内直接用，过期才后台静默更新，正在看的台不打断。
- **节目单**：优先用播放列表声明的地址，未声明时同源推导并保留凭证路径段；XMLTV 流式解析，展示当前与下一节目。
- **断线自愈**：出错自动重开最多 3 次（1/2/4 秒退避），连续 15 秒缓冲不前进也主动重连；播满 20 秒归还重试额度。错误码常驻显示在换台提示与设置里。
- **换台预热**：在当前台停留 3 秒后，请服务端预先取好同分组下一个台的票据与清单，下次切过去更快；失败静默，不影响播放。
- **解码可选**：自动 / 硬解 / 软解三档，本地持久化。自动档硬解优先、软解兜底；可在设置里查看实际启用的解码器。
- **电视适配**：以 960dp 为基准等比缩放，32–100 寸界面占比一致；TV/手机图标与名称统一为「魅影TV」。
- **在线更新**：设置页检查新版本、显示更新说明、断点安全下载并调起系统安装器。更新地址已内置，设备无需手动配置；用户仍可在设置里改成自己的地址。

## 系统要求

- Android 5.0（API 21）及以上。Compose 与 Media3 的下限在此，Android 4.x 无法安装。
- 手机与 Android TV 共用同一个安装包；电视端支持 32 寸至 100 寸屏幕。

## 工程组成

- **Web 原型**：用于验证订阅解析、节目单发现、源管理与配对链路，含单元测试与端到端冒烟测试。
- **Android 原生工程**：Kotlin + Jetpack Compose + Media3，含数据层、播放控制、配对服务、两端界面与单元测试；附 Gradle Wrapper，可直接命令行构建。

两部分共用同一套解析规则。

## 构建

需要 JDK 17 与 Android SDK。在工程根目录执行：

```bash
cd android
./gradlew assembleDebug testDebugUnitTest
```

产物在 `android/app/build/outputs/apk/debug/`，文件名带版本号。

## 在线更新部署

`release/update.json` 是版本清单，`release/apk/` 放当前安装包（只留最新版一个）。把这两个路径按同样结构放到任意静态托管即可，各平台 raw 直链都可以。

```json
{
  "versionCode": 21,
  "versionName": "0.4.7",
  "apk": "apk/iptv-player-0.4.7.apk",
  "notes": "本版更新说明"
}
```

`apk` 写相对路径时按 update.json 所在目录拼接。`versionCode` 必须严格大于已安装版本，否则 App 判为「已最新」。仓库需公开，私有仓库的 raw 链接 App 读不到。

## 设计取舍

- 播放内核用 Media3，直播场景交给播放器原生处理自适应码率。
- 二维码由设备端生成，不引入摄像头识别，添加源只需另一台手机扫一扫。
- TV 配对用轻量本地 HTTP 服务，不依赖外部账号或云端中转。
- 订阅地址中的访问凭证原样保存与透传，不做特殊解析。
- 大量直播源使用明文 HTTP，客户端允许明文流量；使用者应自行评估网络环境。
- 仓库配置为国内镜像优先、官方源兜底，境外构建环境可直接使用官方源。
